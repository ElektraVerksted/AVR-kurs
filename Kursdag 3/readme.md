# AVR Kurs Dag 3
Kursinnholdet på dag tre omhandler noen nyttige kommunikasjonsprotokoller og gode tips for hvordan å ryddig strukturere et prosjekt. Oppgaven er en større oppgave hvor dere får prøve dere på I2C ved å bruke ferdigbygde biblioteker. 
MCC må tas i bruk i en liten grad for å få bibliotekene til å fungere, men hvor mye dere ønsker å bruke MCC for resten av oppgaven er opp til dere.
